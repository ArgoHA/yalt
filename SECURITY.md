# Security policy

## Supported versions

Security fixes are applied to the latest released version of yalt.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for `ArgoHA/yalt`, or contact the maintainer
privately through the address listed on the maintainer's GitHub profile.

Include reproduction steps, the affected version, and the potential impact.
Do not include private images, annotations, credentials, signing material, or
project databases unless a secure transfer method has been agreed first.
